## [Unreleased]

### Changed
- recall-extra benchmark: every injector now chooses candidate files ONLY from the files the default scan actually scans. Candidate lists are derived from a real clean scan of the temp copy through the built unshit (`scan.files`, no cache; new `scannedSourceFiles` in `benchmark/recall-extra/inject.mjs`, reusing `injectionScope().scannedFiles` when supplied, which can only narrow the pool); the injector's ts-like/non-test base listing is intersected with that scanned set. Removed the injector's private `excluded` regex. No detectors changed, no rule tuning, same seeds and counts. Previously injections could land in scan-invisible dirs (e.g. `fixtures/`).
